# QQ 人设机器人（DeepSeek）

一个跑在 Docker 里的 QQ 号：有固定人格、会记住你、记得的东西会随时间淡忘和加固、说话像真人在手机上打字。

```
你的 QQ ──▶ NapCat（QQ 协议端）──▶ bot（本项目）──▶ DeepSeek API
                                      │
                                      └── data/bot/bot.db（所有记忆）
```

## 目录

```
qq-persona-bot/
├─ docker-compose.yml   两个容器：napcat + bot
├─ Dockerfile
├─ .env                 你的 key 和参数（已填好 key，别外传）
├─ persona/
│  └─ persona.yaml      ★ 人格内核，改这里换人
├─ app/                 代码
├─ scripts/smoke_test.py  离线自测，不联网
└─ data/                运行后产生（数据库、QQ 登录态）
```

## 一、部署到飞牛

**1. 装 Docker**
应用中心 → Docker → 安装。

**2. 把整个 `qq-persona-bot` 文件夹传到 NAS**
用飞牛的文件管理上传，或者 SMB 拖进去。放在比如 `/vol1/1000/docker/qq-persona-bot`。

**3. 构建并启动**
飞牛 Docker → 项目 → 创建项目 → 选这个文件夹里的 `docker-compose.yml`。

或者开 SSH 跑：

```bash
cd /vol1/1000/docker/qq-persona-bot
docker compose up -d --build
```

国内拉不到镜像的话，先给 Docker 配个镜像加速（飞牛 Docker 设置里可以填）。

**4. 登录 QQ 小号**
浏览器打开 `http://NAS的IP:6099/webui`
登录 token 在容器日志里：`docker logs napcat | grep -i token`
拿小号扫码登录。

**5. 打开 OneBot 正向 WebSocket**
NapCat 面板 → 网络配置 → 新建 → **WebSocket 服务器**：

- host：`0.0.0.0`
- port：`3001`
- token：和 `.env` 里的 `ONEBOT_TOKEN` 一模一样
- 启用

**6. 重启 bot 容器**
`docker restart qq-persona-bot`

看日志：`docker logs -f qq-persona-bot`，出现 `OneBot 已连接` 就成了。给小号发条消息试试。

## 二、改人设

打开 `persona/persona.yaml`，`core` 下面全部重写成你想要的。改完在 QQ 里发一条 `#重载`，或者 `docker restart qq-persona-bot`。

**`core` 是绝对不会忘的部分**：每一轮对话都会把这段原文塞进系统提示词，不参与任何压缩和遗忘。

**`state` 是会变的部分**：心情、关系熟悉度、最近在意的事。它会随着聊天慢慢变化，存在数据库里，改 yaml 不影响已经形成的样子（想重置就删掉 `data/bot/bot.db` 里 `persona_state` 那行，或者整个库删了重来）。

## 三、记忆是怎么工作的

这是这个项目跟普通"把聊天记录全塞进去"最大的区别：

| 层 | 是什么 | 进不进上下文 |
|---|---|---|
| 人格内核 | yaml 里的 `core` | **每轮都进**，原文 |
| 最近原文 | 最近 24 条对话 | 每轮都进，超 1200 token 截断 |
| 事实条目 | 从聊天里抽出的稳定信息（生日、工作、口味…） | 相关的才进，最多约 700 token |
| 回忆片段 | 每攒够 12 条，压成一段 80 字的"回忆" | 相关的才进，最多 3 段 |
| 原始记录 | 所有消息永久存在 SQLite | **永远不进上下文**，只用来重新压缩和查证 |

**遗忘**：一段回忆很久没被想起，重要度会衰减，低于阈值就"休眠"——不再自动出现在上下文里，但内容还在库里，以后聊到相关话题还能被搜出来。这就是"忘掉细节但没真删"。

**加固**：被反复想起的事，重要度会往上加，越来越不容易忘。

**人设会变**：每 4 段回忆做一次反思，更新心情、关系熟悉度、最近在意的事。单次关系熟悉度最多漂移 0.06，防止一次聊天从陌生人变生死之交。

**省 token**：一轮对话的上下文大约是「内核 600 + 记忆 1500 + 最近原文 1200」token 封顶，不会随着聊天变长而无限膨胀。

## 四、回复节奏与行为控制

她不是"收到就立刻答"，而是按一套节奏规则行动（`app/pacing.py`）：

**回多快**
- 35% 的概率秒回（0.15–0.6 秒），像一个本来就在看手机的人
- 其余按字数算：读消息 0.45s 起，打字 0.25s + 0.05s/字，都有随机浮动
- 深夜整体放慢 1.3–1.6 倍

**想多深**（按你发的内容自动判断，不额外花钱）
- 0 档：随口一句 → 回复上限 200 token，提示它"短点"
- 1 档：需要接住 → 450 token
- 2 档：问了原理、要方案、要步骤、带情绪 → 900 token，提示它"认真答"
- 触发 2 档的信号：问号、超过 40 字、"为什么/怎么/帮我/配置/代码/建模/公式"这类词

**什么时候不回**
- 半夜 1–8 点被吵醒：55% 概率过 2–8 分钟才迷迷糊糊回
- 上课/上班时段（`BUSY_HOURS`）：45% 概率晚 3–15 分钟回
- 心情不好 + 你只发了很短的几个字：25% 概率装没看见
- 只发了"嗯""哦""在吗"：8% 概率直接不理
- 延迟回复时会先来一句"刚在忙 才看到"，而且等待期间你发了新消息，这条作废

**怎么把天聊下去**
- 回完之后 35%–55% 的概率会隔 5–35 秒再补一句（聊得越深越容易补），像突然想起来一样
- 上一句是"句号式收尾"（没反问）的时候，还会再加 15% 概率
- 补话只在对方还没回的时候发；对方已经回了就不补
- 你连着发两三条，有时它会等 4–9 秒，让你把话说完再一起回
- 语气和话题由它自己决定：补充没说完的、想到相关的事、反问一句，或者说说自己的感受

**什么时候主动找你**
- 不是随机撒网，是**按作息时间点唤醒**：默认早上 8:30–9:30、中午 12:00–13:00、晚上 21:00–23:00
- 每个时段当天随机挑一个分钟点，到点醒来判断要不要发
- 刚聊过 30 分钟内不发，每天最多 3 条，深夜不发
- 不同时段说不同的话：早上问今天忙不忙、中午问吃没吃、晚上问累不累

这些都能在 `.env` 里调：`FAST_REPLY_CHANCE`、`SKIP_ENABLED`、`BUSY_HOURS`、`WAKE_SLOTS`、`PROACTIVE_DAILY_MAX`。

## 四点半、接你的课表和日程

鲸鲸会读 NAS 上「任务中心」的 `GET /api/state`，把今天的课和最近的截止时间放进上下文：

- 知道你现在在不在上课，不会在课上催你
- 知道最近有什么要做，快到点了会提一句
- 主动发消息的时候会就着这些说，不是凭空找话题
- 缓存 10 分钟，读不到就用上一次的，不会打断对话

`.env` 里配：

```ini
SCHEDULE_URL=http://<NAS 内网 IP>:8787
SCHEDULE_TOKEN=和任务中心 docker-compose.yml 里的 TOKEN 一致
```

**提醒**：直接说"明天下午三点提醒我交作业"就行，它会在回复后面带一行内部标记，系统解析后真的设好提醒。也可以用命令 `#提醒 明天 15:00 交作业`。

**特殊日子**：写在 `persona/dates.yaml`，`MM-DD` 表示每年都过，`YYYY-MM-DD` 表示只此一次。到那天它会知道。

## 五、QQ 里的命令

只对 `OWNER_QQ` 生效：

| 命令 | 作用 |
|---|---|
| `#记忆` | 看它现在记得什么 |
| `#人设` | 看当前心情和关系状态 |
| `#档案` | 看你的个人档案 |
| `#设定 你其实很怕冷场` | 让它记住对自己的认识 |
| `#习惯 说话多用省略号` | 调它的说话方式 |
| `#提醒 明天 15:00 交作业` | 设一个提醒 |
| `#任务` | 看今天的课和最近的安排 |
| `#遗忘 工作` | 忘掉一条事实 |
| `#遗忘 12` | 让第 12 段回忆休眠 |
| `#压缩` | 立刻把未整理的消息压成回忆 |
| `#重载` | 重新读 persona.yaml |

## 六、参数调优

都在 `.env` 里，改完 `docker restart qq-persona-bot`：

| 参数 | 作用 |
|---|---|
| `TEMPERATURE` | 1.0 稳，1.3 跳脱。默认 1.1 |
| `HISTORY_LIMIT` / `HISTORY_TOKENS` | 最近原文多少进上下文，调大更连贯更费钱 |
| `MEMORY_TOKENS` | 长期记忆预算 |
| `EPISODE_THRESHOLD` | 多少条消息压缩一次，调小记忆更细但更费 |
| `REFLECT_EVERY` | 多久反思一次人设 |
| `PROACTIVE_PER_HOUR` | 主动发消息频率，不想要就设 `PROACTIVE=false` |
| `QUIET_START` / `QUIET_END` | 作息 |

**换模型**：`MODEL=deepseek-chat` 可以换成任何 OpenAI 兼容接口的模型，同时改 `DEEPSEEK_BASE_URL`。

## 八、注意

- **小号风险自担**：走的是非官方协议，腾讯封号是常态。新号先养几天，别一上来就高频发消息。
- **`OWNER_QQ` 一定要填**，否则谁加它都能聊，记忆库会被别人污染。
- **数据库里是真实聊天记录**，`data/bot/bot.db` 别随手传给别人。
- **`.env` 里有你的 API key**，这个压缩包传完就删掉。
- 拿它去冒充真人骗别人，后果是账号和你自己的责任，跟工具无关。
